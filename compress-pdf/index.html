Compress PDF Online

ToolSarthi's PDF compressor helps you create a smaller PDF file that is easier to store and share.

How to compress a PDF?

1. Select your PDF file.
2. Click the Compress PDF button.
3. Wait for processing to finish.
4. Download the resulting PDF.

Is this PDF compressor free?

Yes. This tool is designed to be free to use.

Are my PDF files uploaded?

This first version processes the file in your browser. The selected PDF is not intentionally uploaded to our server.

Important note

PDF compression depends on how the original PDF was created. Some PDFs may become only slightly smaller because their contents are already compressed.
